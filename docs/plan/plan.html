End-to-end implementation plan v6, 1 October 2026. Written so any agent can pick up a task. The Markdown brief (copy button on the version page) is the authoritative execution document; this page mirrors it with the diagrams.

What's new in v6
  • The folder move is done. The repo is ~/dev/ghosthand and the T3 project "ghosthand" points at it. The old "GhostHand" project still points at the old path and should be archived in the T3 UI.
  • Stack and standards are settled (§2 and §4): React 19 + Tailwind v4 + shadcn/ui, TanStack Query + Zustand + TanStack Router, plain TypeScript with typed Result errors, Zod v4 schemas with a custom typed IPC, pino logs with redaction, OpenTelemetry traces, no telemetry, three-OS releases from CI.
  • Process is settled: trunk-based with PRs, squash merges and Conventional Commits; unit tests for logic and testbed e2e for the loop; AGENTS.md plus ADRs plus a PostPlan plan per phase; git worktrees per task.
  • Phase 0 and Phase 1 are task lists with IDs, scope, files and acceptance checks. Phases 2–7 are scoped outlines, to be detailed when reached.

0 · How agents work from this plan

  1. Read AGENTS.md and docs/adr/ in the repo, and the relevant note in research/notes/ before a task.
  2. Pick a task by ID (for example P0-04). Work in a git worktree on feat/p0-04-decision-probe. One T3 thread per task.
  3. Done means: bun run check green, acceptance checks met, secrets grep clean, PR with a Conventional Commit title, phase report updated if a decision changed.
  4. Never: paste or log secrets; call chatgpt.com/backend-api; bypass CLI permission prompts; auto-acknowledge provider safety checks; retry a mutating action; treat a model's "done" as success; touch the T3 Code Tailscale route or service.
  5. Report with measured numbers: what was built, measured, broken, and still open.

2 · Decisions, consolidated

Identity, license, repo

GhostHand, "a Jev CUA". GitHub ghosthand under your account, private first. AGPL-3.0-only with a CLA, trademark policy, third-party notices, SPDX headers and a CI license check. No closed SDKs as dependencies.

Toolchain

Bun workspaces (hoisted linker, trusted deps) for install and scripts; Node 24 for the engine, Playwright, CLI and Electron. electron-vite, electron-builder, Vitest, Playwright Test, Biome, tsgo, Vite 8, React 19, changesets. Switch to pnpm only if Bun gets in the way.

Core style

Plain TypeScript, async/await, typed Result errors at package boundaries; exceptions only for bugs. Zod v4 schemas in @ghosthand/protocol for everything that crosses a process; custom typed IPC validated in the main process; engine in a utilityProcess.

UI

React 19 + Tailwind v4 + shadcn/ui; TanStack Query for engine data, Zustand for UI state, TanStack Router. Device theme from day one (light and dark both first-class), dense, developer-tool feel, modern, monospace for data, teal accent.

Models

Jev direct via TypeSafe, pinned jev-1.13.0, 2.5 s timeout. Phase 1: OpenAI key + Codex consultant. Phase 2: Sign in with ChatGPT (Plus OK, Pro recommended). Phase 6: Claude Code consultant, Anthropic, Google, OpenRouter, local. Per-role model selector; defaults chosen by measurement.

Browser, secrets, storage

Installed Chrome/Edge/Brave; persistent GhostHand profiles; Chrome profile import by copy. Secrets in Electron safeStorage (settings UI) or ~/.config/ghosthand/env for CLI/dev. SQLite index plus one folder per run.

Speech (Phase 4)

Moonshine local default, Whisper downloads for other languages, hosted STT via keys. No Parakeet or custom endpoints in v1.

Process

Trunk-based, PRs, squash merge, Conventional Commits. Unit tests for logic, testbed e2e for the loop, coverage reported not enforced. AGENTS.md + ADRs + PostPlan per phase + GitHub issues. Worktrees per task, no PR size limit, one task per PR. pino + redaction, OpenTelemetry, no telemetry. Releases for Linux, Windows, macOS.

6 · Standards agents must follow

Code

kebab-case filenames, one concern per file, named exports only, no default exports, no barrels except the package entry, no circular imports, every package declares its own deps. Strict TS with noUncheckedIndexedAccess and exactOptionalPropertyTypes. No any.

Errors, logs, traces

Result with discriminated-union errors at boundaries. pino child logger per package with a redaction hook. One OpenTelemetry span per run, subgoal, step and model call, written to the run folder.

Secrets

A secrets registry resolves names at action time; models only ever see [input:NAME]. CI greps run folders, logs and the repo for test secret values.

Tests and docs

Vitest tests next to sources, recordings for model calls, e2e under the testbed. Paid-API probes are explicit scripts and never run in CI. AGENTS.md, docs/adr, docs/architecture.md, CONTRIBUTING.md, SECURITY.md.

12 · Risks

  • Jev via OpenRouter never reaches parity → stay direct; the interface keeps the door open.
  • Sign in with ChatGPT changes → consultants and API keys cover planning; nothing depends on the plan.
  • Anthropic tightens CLI policy → the Claude consultant is optional and late; API keys always work.
  • Bun friction → decide at the end of Phase 0; pnpm migration is a one-day task.
  • Jev accuracy below community numbers → gates escalate; Phase 0–1 measurements set the defaults.
  • Scope creep → each phase has its own plan and report, reviewed before the next starts.
Before Phase 0 starts: archive the old "GhostHand" T3 project (it points at the removed folder), open threads from the "ghosthand" project, and put TYPESAFE_API_KEY in ~/.config/ghosthand/env with owner-only permissions. Then say go.
