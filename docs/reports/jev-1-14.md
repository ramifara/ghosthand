Measured 2026-10-17 on the testbed (127.0.0.1:4400), headless Chrome 151, `--planner none --writer none` (Jev only, no LLM), one attempt per task unless stated. Plan: PostPlan `ghosthand-jev-1-14-images-box`, step 10. Decisions: ADR 0020. Raw logs: `~/.local/share/ghosthand/evals/20261017-*`.

## Reading

1. **D0 is a clear win at negligible cost.** Grounding mode lifts the suite from 77 % to 91 % for +7 % cost ($0.003 of images over 44 tasks). D0 touched 3 % of steps and only when the table had no target. Default stays `grounding`.
2. **Do not flip the default to `always`.** With a screenshot on every act request the pass rate drops to 73 % and cost rises 62 %. Two things change at once in (c): the image, and the model that decides (every request with an image goes to `jev-1.14.0`). (d) shows 1.14 deciding on text alone is not worse than 1.13, so the drop comes from the image itself: Jev's `target` choice gets worse with ~3k tokens of screenshot next to the element table, and the step after a secret is typed runs without the image it had just learned to use. The `always` level stays available as an experiment, off by default.
3. **The text pin can probably move to 1.14.0, after a proper run.** On n = 1, 1.14 text-only passed 36 vs 34 and lost nothing the baseline had except `l2-toast-undo` and `l3-tags-multiselect`, both timing-sensitive tasks that also failed in (c). Each pass count here is one attempt per task; two tasks either way is inside the noise. Before moving the pin (needed anyway before 1.13.0 retires): run L1–L6 with n = 5 for both pins on an idle machine and compare per task. Until then `jev-1.13.0` stays.
4. **Latency.** A D0 look is one more Jev request (about 300 ms) plus one screenshot; a D0 step costs about $0.0001 more than a text step. Median step time did not move between (b) and (d) within noise.

## Recommendation

- Keep `decision.images = grounding` as the default. Done in this PR.
- Keep `decision.visionModel = jev-1.14.0` and the text pin `jev-1.13.0`.
- Follow-up (separate PR, after an n = 5 comparison on an idle machine): move the text pin to `jev-1.14.0` before 1.13.0 is retired.
- Follow-up: `l4-canvas-chart` and other read-a-number tasks need a vision *describe*; keep them on the LLM vision reviewer.
- Follow-up: investigate why `always` hurts the element-table choice (instruction wording, image placement, or the 1.14 vision model's text choice) before any further `always` experiment.
